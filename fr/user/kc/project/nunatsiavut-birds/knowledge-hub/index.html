Qu'est-ce que le carrefour des connaissances?

Comment vos jeux de données sont reliés

Le carrefour des connaissances cartographie les liens entre les produits de données de votre projet. Les liens montrent où un jeu de données est dérivé d'un autre et quels jeux de données alimentent le même rapport — vous pouvez ainsi retracer la lignée, repérer les dépendances communes et comprendre l'effet d'entraînement de la modification d'un seul jeu de données. Faites glisser les nœuds pour explorer, ou sélectionnez-en un pour examiner ses connexions.
